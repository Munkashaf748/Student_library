# DTU Student Library

This project was made by **Munkashaf Alam, Nikhil Kumar, and Atishay Jain** for the **Web Designing mini project (CS103)**.

## About the project

DTU Student Library is a simple collection of HTML pages for first-year engineering students. The home page links to branch pages, where students can see subject names and course codes based on the provided first-year timetable.

The project uses beginner-friendly HTML and CSS. Subject PDF links are not included yet; they can be added to the relevant branch pages later.

## Pages

- `front_page.html` - Home page with links to the timetable and branch pages.
- `cse.html` - Computer Science Engineering.
- `civil.html` - Civil Engineering.
- `ece.html` - Electronics & Communication Engineering.
- `mechanical.html` - Mechanical Engineering.
- `m&c.html` - Mathematics & Computing.
- `ee.html` - Electrical Engineering.
- `physics.html` - Engineering Physics.
- `environment.html` - Environmental Engineering.
- `biotech.html` - Bio-Technology.
- `polymer.html` - Polymer Science & Chemical Technology.
- `product.html` - Production Engineering.
- `eee.html` - Electrical & Electronics Engineering.
- `mechauml.html` - Mechanical Engineering with Automobile specialization.
- `se.html` - Software Engineering.
- `it.html` - Information Technology.

## Open the project

Open `front_page.html` in a web browser. Select a branch to view its subjects. Use the Time Table link on the home page to open the timetable.
